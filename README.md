# Sora Text Batch Runner

Tiện ích Chrome giúp chạy prompt hàng loạt cho Sora trong Sora ChatGPT
và hỗ trợ quét / click tải nhiều video.

Cách cài:
1. Mở `chrome://extensions`
2. Bật **Developer mode**
3. Nhấn **Load unpacked** và chọn thư mục chứa các file này.
4. Vào `https://sora.chatgpt.com/...` (Sora) – extension sẽ tự chèn Batch UI.
